#### **PERPUSTAKAAN DIGITAL - SISTEM MANAJEMEN PERPUSTAKAAN**

**UTS PEMROGRAMAN WEB - CHELSEA BRILLIANT SYAH PUTRA/242410101079/A**





**Tentang Aplikasi:**

Perpustakaan DIgital adalah aplikasi web sistem manajemen perpustakaan yang dibangun menggunakan Laravel 13, aplikasi ini dibuat sebagai tugas UTS mata kuliah Pemrograman Web.

Fitur utama aplikasi meliputi login yang meneruskan data username ke halaman Dashboard dan Profil, serta menampilkan data koleksi buku secara dinamis dari Controller ke View.



**Framework:**

1\. Laravel 13

2\. Bootstrap 5
